# ちいさな RPG（Life Manager 講習会の練習用）

Life Manager の講習会で使う、練習用のリポジトリ（ひな形）です。
C++ のコンソールアプリ「ちいさな RPG」を、Issue → ブランチ → コミット → プッシュ → プルリク → マージ の順で直していきます。

```
================================
        ちいさな RPG
================================

スライム があらわれた！
--------------------------------
 ゆうしゃ  HP 30 / 30
 スライム  HP 20 / 20
--------------------------------
どうする？  1: たたかう
>
```

## 動かしかた

- **Visual Studio**: `workshop-rpg.sln` を開いて、`Ctrl + F5`（デバッグなしで開始）
- **CMake**: `cmake -S . -B build` → `cmake --build build`

## 課題

Life Manager の「＋ イシュー作成」で、下のテンプレートを選ぶと、課題の Issue ができます。
1 つの課題は 1 つのファイルを直すだけなので、チームで分けても、ぶつかりません（課題 6 だけは、わざとぶつけます）。

| 課題 | 直すファイル | 内容 |
|---|---|---|
| 1 | `src/main.cpp` | 勇者の名前を入れられるようにする |
| 2 | `src/status.cpp` | [バグ] HP がマイナスで表示される |
| 3 | `src/battle.cpp` | やくそうで HP を回復できるようにする |
| 4 | `src/enemy.cpp` | 敵を増やす（ゴブリンなど） |
| 5 | `src/message.cpp` | 勝ったとき・負けたときの言葉を変える |
| 6（おまけ） | `src/main.cpp` | タイトルを変える（2 人で同じ行を直して、競合を直す練習） |

## 進めかた（1 つの課題）

1. **Issue を作る**: 「＋ イシュー作成」→ テンプレートから課題を選ぶ
2. **始める**: 「作業」で Issue を選ぶ（自分の担当になり、ブランチができる）
3. **直す**: Visual Studio で直して、`Ctrl + F5` で動きを確かめる
4. **コミットしてプッシュ**: 「作業」で変えたファイルにチェック → 要約を書いて「コミットしてプッシュ」
5. **プルリクを作る**: 「プルリクを作る…」→ 題名と説明を確かめて作る
6. **マージ**: 変更を確かめて（チームなら仲間が「承認する」）→「マージする」

## チームで（2 人以上）

1. リーダーがこのひな形から、チームのリポジトリを作る（GitHub の「Use this template」）
2. リーダーが Life Manager の「設定 → 接続」から、メンバーを招待する
3. 課題を分ける（ボードで付箋を下の机に置くと、自分の担当になる）
4. それぞれ、上の「進めかた」で直してプルリクを作る
5. 相手のプルリクを「変更されたファイル」で見て、「承認する」
6. 承認されたら「マージする」
